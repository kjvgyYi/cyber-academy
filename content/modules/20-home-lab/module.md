Домашняя лаборатория — твоя личная площадка для безопасных экспериментов. Хорошо настроенная лаба позволяет практиковать любые техники из роадмапа не выходя за рамки собственного железа. Она же — наглядное доказательство для работодателя: «я не просто прочитал туториал, я настроил это сам».

Продвинутая лаборатория выходит за рамки «Kali + Metasploitable»: pfSense с сегментацией (Kali в отдельном VLAN, жертвы в другом, Security Onion мониторит весь трафик), Windows AD domain controller, уязвимые машины из VulnHub, возможно ProxMox вместо VirtualBox для более гибкого управления ресурсами.

```tip Начни с малого
Не нужно всё сразу. Начни с M0 стенда (Kali + Metasploitable). По мере прохождения модулей добавляй компоненты. Proxmox или VMware ESXI на старом ноутбуке — хорошее следующее вложение.
```
