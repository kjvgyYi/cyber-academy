SOC аналитик проводит большую часть рабочего дня в SIEM — системе которая агрегирует логи, коррелирует события и генерирует алерты. ELK Stack — де-факто стандарт open-source SIEM. Wazuh добавляет File Integrity Monitoring, vulnerability assessment и агентов на хосты.

Ключевое понимание этого модуля: SIEM бесполезен без правильных правил корреляции и тюнинга. Дефолтные правила генерируют тысячи false positives. Написание собственных правил требует понимания как именно выглядит атака в логах — это знание, накопленное в Модулях 5–8, здесь применяется в обратную сторону.

```info Лабораторная среда
ELK Stack + Wazuh запускается на собственном сервере или VM. Рекомендуется: 4GB RAM для Elasticsearch, отдельная VM для агентов. Docker Compose конфиг доступен в официальной документации.
```
