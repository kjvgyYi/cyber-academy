## Learning Objectives

После урока ты сможешь:

- Объяснить своими словами, что такое cybersecurity и что именно она защищает.
- Назвать основные направления и в двух словах сказать, чем занимается каждое.

- Объяснить, почему разрешение важнее инструмента.

## Theory

### Что это

**Cybersecurity** — это защита компьютерных систем, сетей и данных от несанкционированного доступа, изменения и вывода из строя.

**Зачем нужна.** Почти всё сегодня хранится и работает в цифровом виде: банки, больницы, электростанции, твой Telegram. Если злоумышленник получает доступ, он может украсть данные, подменить их или остановить работу системы.

**Как работает.** Защита строится вокруг трёх целей. Подробно разберём их в M1, пока хватит интуиции:

| Цель | Простыми словами | Пример нарушения |
|---|---|---|
| **Confidentiality** (конфиденциальность) | Чужие не читают | Утечка паролей |
| **Integrity** (целостность) | Никто не изменил тайком | Подмена номера счёта в письме |
| **Availability** (доступность) | Система работает, когда нужна | Сайт положили DDoS-атакой |

### Направления

| Команда | Роль | Чем занимается |
|---|---|---|
| 🔵 Blue Team | SOC Analyst | Смотрит alerts, отличает реальную атаку от ложной |
| | Incident Response | Останавливает атаку, вычищает, восстанавливает |
| | Digital Forensics | Восстанавливает картину по логам, файлам, памяти |
| | Threat Intelligence | Изучает, кто и как атакует |
| 🔴 Red Team | Pentester | По договору ищет уязвимости и пишет отчёт |
| | Red Team Operator | Имитирует реальную атакующую группу скрытно |
| 🟣 Purple Team | — | Red и Blue вместе улучшают обнаружение |
| ⚙️ Build | Security Engineer | Проектирует и настраивает защиту |
| | AppSec | Безопасность кода и веб-приложений |
| | Automation | Пишет инструменты, которые делают рутину |
| 📋 GRC | Governance/Risk/Compliance | Политики, стандарты, аудит (ISO 27001, DSGVO) |

Наш курс покрывает в основном Blue Team, Red Team и Automation.

### Главное правило: разрешение

> Одно и то же действие бывает работой pentester'а или преступлением. Разница только в разрешении.

Nmap-скан собственной VM — это учёба. Тот же скан чужого сервера без разрешения — как минимум серьёзная проблема, а при попытке проникнуть — уголовное дело.

```info Германия — ключевые параграфы StGB
- **§202a** Ausspähen von Daten — доступ к защищённым данным в обход защиты.
- **§202b** Abfangen von Daten — перехват чужих данных при передаче.
- **§202c** Vorbereiten… — подготовка к §202a/b (создание, распространение, приобретение паролей и инструментов с такой целью).
- **§303a** Datenveränderung — удаление или изменение чужих данных.
- **§303b** Computersabotage — нарушение работы чужих систем.
```

**Важный нюанс §202c.** Сам по себе Kali, Nmap или Wireshark не запрещены. Ключевой вопрос — цель использования. Легальная работа по договору и учёба на своём стенде — нормальная практика в индустрии. Это не юридическая консультация; принцип простой: **работай только на своём или там, где есть письменное разрешение**.

Что считается разрешением: собственные устройства и VM; CTF и учебные платформы в рамках их правил; bug bounty строго в пределах scope; письменный договор на pentest.

## Example

Компания в Лейпциге, ночью идут тысячи попыток входа по SSH на сервер.

| Кто | Что делает |
|---|---|
| SOC Analyst | Видит alert: 5000 неудачных логинов с одного IP за 10 минут |
| Incident Response | Блокирует IP, проверяет, был ли успешный вход |
| Forensics | По логам восстанавливает действия атакующего |
| Pentester | Месяц назад писал в отчёте: «SSH открыт, вход по паролю разрешён» |
| Security Engineer | Отключает пароль, оставляет ключи, ставит fail2ban |
| Automation Engineer | Пишет скрипт, анализирующий `auth.log` и шлющий уведомление |

Последнюю строку ты сам будешь делать в M11–M14.

## Common Mistakes

| Ошибка | Почему неверно |
|---|---|
| «Я ничего не сломал, значит, всё легально» | Уже сам доступ без разрешения может быть нарушением |
| «Kali — хакерская ОС, её незаконно иметь» | Инструменты легальны, значение имеет цель |
| «Cybersecurity = хакинг» | Большая часть рабочих мест — Blue Team, Engineering, GRC |
| «Сначала выберу направление, потом учу базу» | Без базы (Linux, сети) ни одно направление не работает |

## Summary

- Cybersecurity защищает **конфиденциальность, целостность и доступность**.
- Направления: Blue Team, Red Team, Build, GRC.
- **Разрешение важнее инструмента.** В Германии ключевые параграфы — §202a–c и §303a–b StGB.
- Практикуемся только на своём, в CTF и в bug bounty в пределах scope.
