Большинство корпоративных целей работают на Windows. Active Directory управляет аутентификацией и авторизацией для миллионов организаций — и это именно то, что атакуют в 80% реальных пентестов и red team операций. Pass-the-Hash, Kerberoasting, Golden Ticket — всё это требует глубокого понимания как работает Windows.

Модуль охватывает Windows Server и клиентскую Windows с точки зрения безопасности. Ты разберёшь как устроен AD, как Kerberos выдаёт тикеты, где хранятся хеши паролей и что с этим делать. PowerShell здесь — основной инструмент: и для администрирования, и для атак (Living off the Land).

```safety Учебная среда
Весь практикум Windows выполняется только на собственной VM (Windows Server Evaluation доступен бесплатно с сайта Microsoft). Никакой работы с рабочими или корпоративными машинами.
```
